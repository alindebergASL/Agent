# Batch source reads while retaining line references

For independent text files, use one hosted program to call the bounded file reader once per file. Carry the file ID and numbered lines forward with each result. Calculate the totals through direct calls and separate per-shipment costs from fixed per-order costs before comparing scenarios.

The live quote run verified this method. A single program read lines 1–2 of both supplier files. The saved comparison and recommendation cited line 2 and matched PR #1’s direct-call totals and winners at both shipment counts.
